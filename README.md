# 地材決標雷達

可搜尋、篩選、整理與匯出台灣公共採購地材決標公告的輕量網站。

## 啟動

需要 Node.js 18 以上，不需安裝套件：

```powershell
npm start
```

GitHub Pages 會由 `.github/workflows/pages.yml` 自動部署。GitHub Actions 每 6 小時執行 `scripts/sync.mjs`，抓取臺南市政府工程、勞務與財物決標公告資料，再更新網站。

## 資料取得原則

- 優先使用政府資料開放平臺所列、適用「政府資料開放授權條款第 1 版」的 API 或下載檔。
- 內建「臺南市政府工程決標公告資料」官方 API 同步入口。
- 全國或其他機關資料可用 JSON / UTF-8 CSV 匯入。可辨識欄位：`機關名稱`、`案名`、`決標日期`、`得標廠商`、`決標金額`、`公告連結`（也支援相對應英文欄位）。
- 只收錄案名或內容含地板、地毯、PVC 地磚、木地板、架高地板、導電／防靜電地板等關鍵字的資料。
- 不以自動爬蟲高頻掃描政府電子採購網；該站用作原公告查閱連結。

正式上線前，建議以排程呼叫經確認授權的官方 API 或匯入官方下載檔，並保留資料提供機關、資料集版本／年份與原公告網址，以履行顯名義務。
